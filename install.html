Download & Installation

Die aktuellen Installer stehen in den Releases – pro Plattform ein Installer, jeweils mit einer GPG-Unterschrift (Datei .sig).

Zu den Downloads Änderungen je Version

Verfügbare Versionen

System Datei Installation unter
Windows 10/11, 64 Bit AmpNerd-‹Version›-Windows-Setup.exe C:\Program Files\Common Files\VST3\Amp Nerd.vst3
macOS 10.15 + (Apple Silicon und Intel) AmpNerd-‹Version›-macOS.pkg /Library/Audio/Plug-Ins/VST3 und /Library/Audio/Plug-Ins/Components

Vor der Installation

  • Den Host schließen (Studio One, Cubase, Reaper, Logic …), danach neu starten bzw. die Plugins neu scannen.
  • Das Plugin erscheint als Amp Nerd von Wurzelpeter – als Insert auf einer Gitarrenspur (Mono-Eingang, Stereo-Ausgang).

Beim Start – einmalig

Die Installationsdateien sind nicht signiert bzw. von Apple nicht attestiert:

  • Windows: Erscheint „Der Computer wurde durch Windows geschützt“: Mehr erfahren → Trotzdem ausführen. Deinstallation über Einstellungen → Apps.
  • macOS: Erscheint eine Warnung: Rechtsklick auf die Datei → Öffnen, oder Systemeinstellungen → Datenschutz & Sicherheit → trotzdem öffnen.

Die .sig-Datei neben jedem Installer ist die GPG-Unterschrift. Wer die Signatur prüfen möchte, kann sie mit dem öffentlichen Schlüssel von Wurzelpeter verifizieren (siehe Releases).

Updates

Der Knopf Updates oben links im Plugin zeigt neue Versionen samt Änderungen und startet den Installer. Beim Öffnen des Plugins wird höchstens einmal am Tag nachgesehen.

Systemvoraussetzungen

  • Windows: 64-Bit-VST3; CPU mit AVX2 (Intel ab 4. Generation „Haswell“ 2013; AMD ab Ryzen).
  • macOS: 10.15 + mit VST3 und Audio Unit, auf Apple Silicon und auf Intel.

Die Simulation ist rechenintensiv – je nach Modell ca. 40–55 % eines CPU-Kerns (gemessen auf einem aktuellen Desktop-Prozessor) bei Qualität „Normal 4x“. „Eco 2x“ braucht etwa die Hälfte, „Hoch 8x“ das Doppelte.

Eingangspegel einpegeln

Wichtig für den Sound: Die Eingangsanzeige oben im Plugin zeigt typische Bereiche von Single-Coil und Humbucker. Liegt die Anschlagsspitze daneben, mit EINGANG dB abstimmen – sonst klingt jeder Verstärker zu sauber oder zu verzerrt.

Weitere Hinweise: Die macOS-Version wird automatisch gebaut und von Apples AU-Prüfwerkzeug getestet. Songs aus der Vorgängerversion „Amp Circuit Simulator“ werden nur von der jeweiligen Version geladen – Amp Nerd ist ein eigenständiges Plugin.

Rückmeldung

Fehler, Abweichungen, Klang, Bedienfluss, Text – am besten als Issue mit Host, Betriebssystem und gewähltem Verstärker. Besonders willkommen: Berichte von echten Macs, da die macOS-Version bisher nur maschinell getestet wurde.

Hinweise

Die Simulation ersetzt keine Arbeit an echten Röhrenverstärkern – dort liegen lebensgefährliche Spannungen an. Marshall, JCM800, JTM45, Silver Jubilee und weitere genannten Namen sind Marken ihrer jeweiligen Inhaber; dieses Projekt steht in keiner Beziehung zu ihnen. Die Namen beschreiben lediglich die nachgebauten Schaltungen.

Dieses Repository enthält ausschließlich Installer; der Quellcode ist nicht öffentlich.
